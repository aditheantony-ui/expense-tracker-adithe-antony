# Expense Tracker

A simple responsive Expense Tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Edit and delete transactions
- Track total income, total expenses, and balance
- Filter transactions by type and category
- Monthly expense summary
- Category-wise expense chart
- Form validation
- Data persistence using Local Storage
- Responsive design for desktop and mobile

## Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
- Local Storage

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.

Alternatively, use the **Live Server** extension in VS Code and open `index.html` with Live Server.

No backend or installation is required.
